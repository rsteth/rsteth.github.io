# Learning Machines visual language

Warm ivory (#f6f3eb), charcoal (#302e28), accessible muted text (#6b695f), sage GDN slabs, terracotta attention slabs, and ochre converted slabs. Preserve the site's Space Grotesk, Inter, and Space Mono typography. Keep labels and controls in HTML, never rasterize them.

Illustrations use a small fixed-resolution canvas with nearest-neighbour CSS enlargement. Isometric faces use a 2:1 diamond, limited palette and stable pixel-grid dither. No random noise, continuous render loop or GPU dependency. Redraw only on relevant state changes. Homepage slab separation runs only for a fine hover pointer with no reduced-motion preference; touch and reduced-motion remain still.

The pinned mechanics module owns all educational values. Presentation must not fabricate model output or benchmarks. Growth is linear and countable: one tile = the whole stack's state at 1,024 tokens, whole tiles plus one partial tile reproduce the exact value, a dot grid shows the 256-tile capacity, and the recurrent column is always one tile. Architecture inspection shows all 64 real layers at once as one strip (two rows of 32 at narrow width), with a viewfinder zoom on the selected block of four, layer-number labels in HTML, all-layer keyboard selection and text patterns (G/G/G/A or D/D/D/C). The record-versus-state toy ends on a recall question both representations answer from the actual six events. The toy's tiles come from the actual six events and two latest-value slots.

Instrument language (v2): hairline-grid panels with viewfinder corner brackets frame anything to look at; one colour per meaning (terracotta = full attention, sage = recurrent/GDN, ochre = hybrid/converted). Token vectors use shape, not colour: dot area = magnitude, filled = positive, ring = negative, tick = zero, rounded value printed beneath. Context weights are arcs whose stroke width is the fixed recipe weight. The token study is one scroll story: a sticky pipeline marks the section in view; every section follows one selected piece; section 03 shows the supplied distribution as one 100% ribbon and, when sampling, a needle at the pinned sampler's own draw (selection.seed / 2^32). Fixed worked examples remain for no-JS readers and are never mutated; live versions appear only once the page is interactive. No autoplay.

Retain semantic HTML, the existing line chart and 64-layer grid as no-canvas fallback. With no JavaScript, leave controls disabled and the initial static explanation readable. Canvas is decorative to assistive technology; native controls, summaries and data lists remain available.

Validation: `node scripts/test-learning-machines.mjs`, `node scripts/test-learning-visuals.mjs`, `node scripts/test-market-river.cjs`. Before a visual revision, test keyboard, touch, narrow width, reduced motion and canvas failure. Do not claim screenshots or browser/device checks that were not performed.
