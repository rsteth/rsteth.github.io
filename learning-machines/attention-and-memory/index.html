02 / attention and memory

How much does a model need to keep?

Some layers keep a growing record of earlier tokens. Others fold each new token into a compact state.

01 / a growing context

More to read. More to keep?

During cached decoding, full-attention layers retain keys and values for earlier tokens. Recurrent layers update a bounded state.

Fixed recurrent state does not mean constant total memory, constant processing cost or perfect recall. Full attention does not guarantee exact retrieval either.

02 / inside the stack

64 layers. Two arrangements.

Qwen3.8-27B repeats three GatedDeltaNet (GDN) layers, then one full-attention layer. A community experiment replaces those attention layers with GDN.

Sources, assumptions & limits

Credit to the Qwen team and summerAIO. Architecture comes from the official Qwen config and community config, rather than the community README's hybrid label. The community config makes all 64 layers linear, converting zero-based layers 3, 7, …, 63.

The author's training report records per-layer distillation, then rank-32 LoRA with native_lora: true. Configured context is 262,144 tokens. Needle results and needle lengths are empty; the training/cache plan goes up to 16,384. This is not evidence of demonstrated 262K retrieval. We ran no models and report no quality scores.

The growth comparison assigns equal abstract units to unlike layer states to show shape only: full = 64n/1024; hybrid = 16n/1024 + 48; recurrent = 64. It excludes weights, activations, buffers, vision and runtime overhead. The recurrent state exists even before any tokens arrive.
